Two users in one household, with opposite needs.

The product only works if a 9-year-old finds it irresistible AND a 34-year-old finds it trustworthy. A Deere-branded farming game for German kids 7–12 that turns brand exposure into measurable learning — designed to scale from a 1.2M launch to 12M+ players. Proposed concept project.

This was never a kids' game with a parent mode. It was a four-party negotiation rendered as an interface.

Deere's brand stays safe only if the learning is real, which is credible only if the parent trusts it, which happens only if the child genuinely loves it. Every decision lived in that tension — and the research showed children and parents wanted opposite things.

Opposite user needs collapsed into four moves that satisfy both at once
